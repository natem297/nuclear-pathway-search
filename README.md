# Nuclear Isotope Production Pathway Search
This project develops a computational tool for identifying potential nuclear reaction pathways to produce a desired isotope from candidate starting materials. Given a target nuclide, the code searches nuclear reaction and radioactive decay data to identify possible precursor nuclides, intermediate products, and multistep pathways leading to the target.

The long-term goal is to support the exploration and comparison of isotope production routes, including pathways involving neutron-, proton-, and alpha-induced reactions, with applications to the production of scarce and technologically important isotopes.

The project aims to provide a foundation for evaluating candidate pathways using reaction data, decay properties, and, eventually, quantitative production estimates under specified irradiation conditions.
